# The launcher's icon

Dainty Lass Launcher and Dainty Lass Manager are the root's MIT Tauri shell, `crates/dainty-launcher-app`, over
`crates/dainty-launcher-kit`, with the manager's embedded server in `crates/dainty-manager-server`. Nothing here is
built into an app.

`brand/icon.png` is today's icon (L2), kept until a new one is drawn; the MIT shell's placeholders stand in for it and
no build reads it. The launcher's AGPL oracle tests (`src-tauri/`, `test/`) were deleted in RB15.
